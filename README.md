# Flick

A modern movie discovery app built with **React, TypeScript, Vite, MUI & Tailwind CSS**.

🔗 **Live Demo:** https://iflick.vercel.app/

## Features

- Search & discover movies
- Movie details & cast
- Ratings, genres & runtime
- YouTube trailers
- Favorites
- Pagination
- Responsive UI
- Loading skeletons
- Type-safe API integration

## Tech Stack

- React 19
- TypeScript
- Vite
- React Router
- Material UI
- Tailwind CSS
- Redux
- ESLint

## Getting Started

```bash
git clone https://github.com/anshumanlabs/flick.git
cd flick
npm install
npm run dev
```

## Build

```bash
npm run build
```
